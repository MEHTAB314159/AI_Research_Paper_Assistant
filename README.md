AI RESEARCH PAPER SEMANTIC SEARCH AND QUESTION ANSWER SYSTEM

> **Abstract** : Research papers contain a lot of information, making it difficult to find answers quickly. This project develops an AI-based system to search research papers and answer questions. Users can upload PDF files and ask questions in simple English. The system extracts and cleans text, divides it into small parts, and finds relevant information using keyword and semantic search. It uses AI to generate answers from the retrieved text. It also shows the source paper and page number. The system is developed using Python and Streamlit and deployed on Streamlit Community Cloud for easy access through a web browser.
